# منصة نيوتن للعلوم

منصة تعليمية للعلوم باسم **منصة نيوتن للعلوم** بإشراف أ/ حسام.

## الحالة الحالية
- واجهة تسجيل دخول عربية RTL.
- لوحة طالب تجريبية.
- المقررات والدروس والتقدم والأنشطة بشكل تجريبي.
- تصميم Responsive.

## الخطوات القادمة
- Supabase Authentication.
- قاعدة بيانات الطلاب والمدرسين والكورسات.
- لوحة الإدارة والمدرس.
- الفيديوهات والملفات والاختبارات والواجبات.
- الاشتراكات والدفع والإشعارات.
- مساعد علوم بالذكاء الاصطناعي.
