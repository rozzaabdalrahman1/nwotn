# منصة نيوتن للعلوم

منصة تعليمية للعلوم بإشراف **أ/ حسام**.

## ما تم تنفيذه
- صفحة دخول عربية RTL مرتبطة بـ Supabase Auth.
- إنشاء حساب طالب وتسجيل دخول وخروج.
- إعادة تعيين كلمة المرور عبر البريد.
- إنشاء Profile تلقائي للمستخدم الجديد.
- توجيه تلقائي حسب الصلاحية: طالب / مدرس / مدير.
- تحميل الكورسات المنشورة من قاعدة البيانات.
- تحميل الوحدات والدروس.
- تسجيل الطالب في الكورس.
- حفظ تقدم الطالب لكل درس.
- نافذة لعرض محتوى الكورس.
- لوحة مدرس ولوحة مدير مبدئية.
- قاعدة بيانات متكاملة للاختبارات والواجبات والدرجات والإشعارات.
- RLS وصلاحيات أساسية لحماية البيانات.

## تشغيل قاعدة البيانات
1. افتح Supabase SQL Editor للمشروع.
2. نفّذ `supabase/schema.sql` بالكامل.
3. أنشئ مستخدم المدرس من Authentication > Users.
4. انسخ UUID الخاص بالمدرس.
5. استبدل `YOUR_TEACHER_UUID` داخل `supabase/setup.sql` بالـUUID الحقيقي.
6. نفّذ `supabase/setup.sql`.

> المفتاح الموجود في `supabase-config.js` هو Publishable/Anon key مخصص للمتصفح. لا تضع أبدًا `service_role` أو أي مفتاح سري في ملفات الموقع.

## الملفات
- `index.html` — بوابة الطالب.
- `app.js` — Auth والبيانات والتقدم.
- `admin.html` — لوحة الإدارة المبدئية.
- `teacher.html` — لوحة المدرس المبدئية.
- `supabase/schema.sql` — الجداول والسياسات والـtriggers.
- `supabase/setup.sql` — إنشاء المدرس ومحتوى تجريبي بعد إضافة UUID.
